      Install as app (Android)

      1. Download certificate
      2. Android settings → Security → More security settings → Encryption & credentials → Install a certificate → CA certificate, and pick the downloaded file.
      3. Open in Chrome, then menu → Install app.
      The certificate is made by your Pi and only works for it. On an iPad, Share → Add to Home Screen works without this.
